# Teacher-made videos

Put short video lessons here (MP4, under 25 MB each so GitHub accepts them through the website).

Then add the video to the lesson in `lessons/weekNN.js`, for example:

```js
videos: [vid("Reading the vertex form (teacher video)", "assets/videos/week07-lesson1.mp4", "Siay NHS")],
```

Larger videos are better uploaded to YouTube (unlisted is fine) and linked the same way.
